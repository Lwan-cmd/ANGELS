# INGENIUM v0.6 — vintage hardware UI

UI-only redesign. DSP and modulation matrix remain unchanged.

Direction: late-70s/80s multitrack / mixer hardware, without copying any brand marks.

- cream painted metal chassis with deterministic wear/scratches
- six vertical pastel channel strips for AGE / MELT / GRAIN / GHOST / SMEAR / CHAOS
- black ridged bakelite-style rotary controls and utilitarian silk-screen scales
- rectangular switches, pilot lamps, screws and vent slots
- bottom OUTPUT / FINISH plate with decorative dual VU meters
- MOD page keeps 3 LFO sections above 4 horizontal cross-mod patch rows
- AIR / WIDTH / MIX remain outside the modulation matrix
